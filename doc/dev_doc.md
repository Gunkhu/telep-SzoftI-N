# Fejlesztői dokumentáció

## Célok

A program célja települések bekérése, tömbben tárolása,
ennek gyakorlása.


## Használt osztályok

* Main
* Solution

### Main osztály

A Main csak a program indítását szolgálja.

### Solution osztály

A Solution osztály két metódussal rendelkezik.
* task01()
* printCity()

A task01() metódus szintaxisa:
```java
List<String> task01()
```
A printCity() metódus szintaxisa:
```java
void printCity(List<String> cityList)
```
